🎓 Guide d'utilisation pour les élèves

  • Taper directement : Commencez à taper votre équation, elle s'affiche en temps réel !
  • Fractions : Cliquez sur "Fraction" ou tapez / puis naviguez avec les flèches
  • Puissances : Utilisez ^ ou le bouton "Puissance"
  • Racines carrées : Cliquez sur "Racine" ou tapez \sqrt
  • Navigation : Utilisez les flèches du clavier pour vous déplacer dans l'équation
  • Grecs : Tapez \ suivi du nom (ex: \alpha, \beta, \pi)
  • Fonctions : sin, cos, tan, log, ln s'affichent automatiquement
